FIX

훅이 백엔드 저장소 작업에만 동작하도록 범위 제한

날짜: 2026-11-11브랜치: fix/hooks-backend-only커밋: 커밋 전 생성

문제 분석

원인

훅 3개가 상대 경로(python .claude/hooks/...)라서 작업 폴더가 프론트로 바뀌면 파일을 못 찾아 매번 오류가 났다.

영향

프론트 저장소 수정마다 훅 오류가 났고, 경로만 고치면 프론트 작업에도 ERD·fix 커밋 규칙이 적용될 수 있었다.

놓친 이유

백엔드 폴더에서만 작업해서, /add-dir로 다른 저장소를 추가해 쓰는 경우를 시험하지 않았다.

재발 방지

scope.py가 대상이 저장소 밖이면 건너뛰고, 명령은 CLAUDE_PROJECT_DIR 절대 경로로 바꿨다. 테스트로 고정했다.
